# Подключение Instagram и Threads к GenAgent

Порядок: приложение Meta → ключи в студию → адреса и вебхуки в Meta → тестировщики → подключение аккаунтов к агентам.
Всё, что нужно вставить в кабинет Meta (адреса, маркер вебхука), студия показывает в разделе **«Интеграции»**
(виден администратору): `https://yabot.taila51a60.ts.net:8459/integrations`.

> Названия кнопок в кабинете Meta меняются; ниже — смысл шагов. Если пункт называется иначе, ищите по смыслу.

---

## 1. Приложение Meta

1. https://developers.facebook.com → **«Мои приложения» → «Создать приложение»**. Название: `GenAgent`.
2. Сценарии (use cases) — добавьте два:
   - **«Управление сообщениями и контентом в Instagram»** (Instagram API со входом через Instagram — страница Facebook не нужна);
   - **«Доступ к Threads API»**.
3. Бизнес-портфолио — портфолио студии (понадобится для проверки бизнеса).

Можно использовать и существующее приложение Threads Puls — главное, чтобы в нём были оба сценария и нужные адреса.

## 2. Instagram

1. Сценарий Instagram → **«Настройка API со входом через Instagram»**:
   - скопируйте **ID приложения Instagram** и **секрет приложения Instagram** → студия, «Интеграции» → блок Instagram → «Сохранить».
2. **«Настроить вход для бизнеса» (Business login settings)** → **OAuth redirect URIs**: вставьте «URL перенаправления (OAuth)» из блока Instagram в студии.
3. **Вебхуки**: «URL обратного вызова» — «URL обратного вызова вебхука» из студии; «Маркер подтверждения» — «Маркер подтверждения вебхука» из студии → «Проверить и сохранить».
   Подпишитесь на поля **`messages`** и **`comments`**.
4. Разрешения: `instagram_business_basic`, `instagram_business_manage_messages`, `instagram_business_manage_comments`.

## 3. Threads

1. Сценарий Threads → **«Разрешения и функции»**: `threads_basic`, `threads_content_publish`, `threads_read_replies`, `threads_manage_replies` — «Готово к тестированию».
2. **«Настройки»** сценария:
   - **ID и секрет приложения Threads** → студия, «Интеграции» → блок Threads → «Сохранить»;
   - «URL обратного вызова для перенаправления» — «URL перенаправления (OAuth)» из блока Threads в студии;
   - «URL обратного вызова для удаления приложения» — «URL отмены авторизации» из студии;
   - «URL обратного звонка для удаления» — «URL запроса на удаление данных» из студии.
3. Вебхуки Threads (по желанию, работают после публикации приложения): подписка на **`replies`**, адрес и маркер — из студии.
   Без них студия сама проверяет новые ответы раз в 2 минуты.

## 4. Общие настройки приложения

**Настройки → Основное**: ссылка на политику конфиденциальности (страница на yabotua.com), иконка 1024×1024,
категория «Бизнес и страницы», «URL удаления данных» — «URL запроса на удаление данных» из студии.

## 5. Тестировщики (пока приложение не прошло проверку Meta)

Пока нет расширенного доступа (App Review), приложение работает только с аккаунтами, у которых есть роль:

- **Роли в приложении → «Добавить людей» → «Тестировщик Instagram»** (ник аккаунта клиента). Клиент принимает приглашение:
  Instagram → Настройки → «Приложения и сайты» → «Приглашения тестировщика» → «Принять».
- **«Тестировщик Threads»** — аналогично; принять: Threads → Настройки → Аккаунт → «Разрешения для веб-сайтов» → «Приглашения».

Аккаунт Instagram должен быть **профессиональным** (бизнес или автор). Для уведомлений о комментариях — ещё и **публичным**.

**Директ Instagram приходит только вебхуками, а Meta шлёт вебхуки только опубликованному (Live) приложению.**
Переведите приложение в режим «Опубликовано» (нужны пункты из шага 4) — тестировщики продолжат работать.
Комментарии Instagram и ответы Threads студия дополнительно проверяет сама (раз в 1–2 минуты), поэтому они работают и раньше.

## 6. Подключение аккаунта клиента к агенту

Студия → клиент → агент → **«Каналы» → Instagram (или Threads) → «Получить ссылку входа»**:

- **«Войти сейчас»** — если вход в аккаунт клиента есть у вас;
- **«Ссылка для клиента»** — скопируйте и отправьте клиенту. Ссылка одноразовая, действует сутки. Клиент входит в свой аккаунт,
  разрешает доступ — и аккаунт сам появляется в «Каналах».

После подключения в карточке канала: «Директ», «Комментарии», «Публичные ответы — на одобрение» (по умолчанию включено:
ответы в комментариях сначала попадают в «Диалоги», публикует менеджер — кнопки «Опубликовать / Изменить / Отклонить»).
Доступ живёт 60 дней и продлевается автоматически.

## 7. Проверка Meta (чтобы работать с любыми аккаунтами клиентов)

Нужны **подтверждённый бизнес** (Business Verification — документы ФОП/компании) и **App Review**:
расширенный доступ для `instagram_business_basic`, `instagram_business_manage_messages`, `instagram_business_manage_comments`
и Threads-разрешений. Для каждого — описание и скринкаст: подключение аккаунта, сообщение клиента, ответ агента,
одобрение ответа менеджером в «Диалогах».

## Ограничения Meta, о которых стоит знать

- **Директ Instagram:** ответить можно только в течение 24 часов после последнего сообщения клиента; сообщение — до 1000 байт
  (длинные ответы студия делит сама).
- **Комментарии Instagram:** ответ — только на комментарии верхнего уровня; на скрытые и комментарии эфиров ответить нельзя.
- **Threads:** личных сообщений в API нет (ни сейчас, ни в планах Meta) — только ответы под постами. Лимит — 1000 ответов в сутки на аккаунт.
- Студия отвечает на комментарии под последними 10 постами за 30 дней.
