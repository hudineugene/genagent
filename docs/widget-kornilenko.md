# Чат агента на сайте Construcciones Kornilenko

План подключения виджета GenAgent к новому сайту (сайт на реконструкции — подключаем после запуска).
Программная база готова: тексты на 4 языках, подсказки, контекст страницы и объекта, команды для сайта,
перенос разговора в Telegram-бот.

## Что уже умеет виджет

| Возможность | Как работает |
|---|---|
| Языки ru / uk / en / es | Язык окна — из `data-lang` или `<html lang>`; незнакомый язык → английский. Агент отвечает на языке страницы (или на языке посетителя, если тот пишет на другом). |
| Тексты по языкам | Заголовок, подзаголовок, приветствие и кнопки-подсказки — отдельно для каждого языка (настройки канала → «Тексты на языках посетителей»). Пустое берётся из основных. |
| Кнопки-подсказки | До 4 кнопок до первого сообщения: «Buscar villa junto al mar», «Reservar una visita»… |
| Контекст страницы | Окну автоматически передаются адрес и заголовок страницы. Агент знает, что посетитель смотрит, и понимает «эта вилла», «эта цена». |
| Контекст объекта | `data-context` у скрипта или `GenAgent.setContext(...)` — код, название, цена, район объекта. |
| Команды сайта | `GenAgent.open()`, `GenAgent.close()`, `GenAgent.ask("…")` — например, кнопка «Спросить об этом объекте» на карточке. |
| Продолжить в Telegram | После первого сообщения в окне — ссылка в @construcciones_kornilenko_bot; бот переносит переписку, консультант продолжает с того же места (код в боте готов: `/start w_<код>`). |
| Всё остальное | Те же база знаний, память о клиенте, передача менеджеру, черновики, утренняя проверка, сводка лидов — разговоры с сайта видны в «Диалогах». |

## Шаги при запуске сайта

1. **Канал.** GenAgent → агент «Консультант по недвижимости» → «Каналы» → «+ Виджет на сайт».
2. **Настройки канала:**
   - цвет — фирменный цвет сайта, положение — справа;
   - «Бот в Telegram» — `@construcciones_kornilenko_bot`;
   - основные тексты (ru) и «Тексты на языках посетителей» для es / en / uk;
   - кнопки-подсказки по языкам, например:
     - es: `Buscar villa junto al mar`, `Reservar una visita`, `Comprar como no residente`
     - en: `Find a sea-view villa`, `Book a viewing`, `Buying as a non-resident`
     - ru: `Подобрать виллу у моря`, `Записаться на просмотр`, `Покупка нерезидентом`
3. **Код на сайте** — один раз в общем шаблоне, перед `</body>`:

   ```html
   <script src="https://agents.yabotua.com/widget.js" data-channel="ID_КАНАЛА" async></script>
   ```

   Язык берётся из `<html lang="es">` каждой языковой версии. Если у сайта его нет — добавить `data-lang="es"` (en, ru, uk) в шаблон каждой версии.

4. **Карточка объекта** — передать, какой объект смотрит посетитель (одно из двух):

   ```html
   <!-- вариант 1: в атрибуте скрипта на странице объекта -->
   <script src="https://agents.yabotua.com/widget.js" data-channel="ID_КАНАЛА"
     data-context="Объект: Villa Sol (V-012); Цена: 550 000 €; Район: Finestrat; Спальни: 4" async></script>
   ```

   ```js
   // вариант 2: из кода страницы (SPA, смена объекта без перезагрузки)
   window.GenAgent?.setContext({ "Объект": "Villa Sol (V-012)", "Цена": "550 000 €", "Район": "Finestrat" });
   ```

   Код объекта (V-012) должен совпадать с базой знаний — тогда агент ответит по своим данным об объекте.

5. **Кнопка «Спросить об этом объекте»** на карточке:

   ```html
   <button onclick="GenAgent.ask('Me interesa Villa Sol (V-012). ¿Sigue disponible?')">Preguntar al asesor</button>
   ```

   Команды, вызванные до загрузки окна, не теряются — выполнятся, когда окно будет готово.

6. **Бот.** Выложить текущую версию бота Корниленко (переход с сайта `/start w_…` уже в коде).

## Проверка после подключения

- Страница на каждом языке: заголовок, приветствие и подсказки — на этом языке; ответ агента — тоже.
- На карточке объекта спросить «¿Cuánto cuesta?» — агент называет цену именно этого объекта.
- Кнопка «Preguntar al asesor» открывает окно и задаёт вопрос.
- «Continuar en Telegram» → бот пишет «Seguimos la conversación de la web», в «Диалогах» переписка с сайта перенесена.
- Телефон: окно на весь экран, клавиатура не закрывает поле ввода.
- Свои проверки — с аккаунтов из «Сотрудники → Тестовые аккаунты» (для сайта посетитель анонимный — тестовый разговор пометить кнопкой «Это тестовый разговор» в «Диалогах»).

## Приватность

Окно хранит в браузере посетителя только случайный номер разговора (localStorage окна на адресе GenAgent) —
это функциональное хранилище, без рекламных cookie. В политике конфиденциальности сайта упомянуть чат и то,
что переписка обрабатывается для ответа на вопросы.

## Что можно добавить потом (не нужно для запуска)

- Ограничение доменов: окно открывается только на сайте компании (заголовок `frame-ancestors`).
- Фото от посетителя (как в боте) и кнопка WhatsApp рядом с Telegram.
- Короткая форма «оставить телефон» прямо в окне.
- Подпись у кнопки чата («¿Dudas? Escríbenos») и мягкое автооткрытие через 30 секунд на карточке объекта.
