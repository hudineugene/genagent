# Почта (Gmail)

Агент читает новые письма во «Входящих» и готовит ответ. По умолчанию ответ — **черновик на одобрение** в «Диалогах»: менеджер жмёт «Опубликовать» (или правит текст), и письмо уходит ответом в ту же ветку, с темой «Re: …». Отправленные ответы видны в папке «Отправленные» Gmail.

## Подключение

1. Войдите в Google-аккаунт ящика (например, yabotua@gmail.com).
2. Включите **двухэтапную проверку**: [myaccount.google.com/security](https://myaccount.google.com/security) → «Двухэтапная аутентификация».
3. Создайте **пароль приложения**: [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords) → название любое (например, `GenAgent`) → «Создать». Google покажет 16 букв — скопируйте их.
4. GenAgent → клиент → агент → вкладка **«Каналы» → «Почта (Gmail)»**: адрес ящика, пароль приложения, имя отправителя (например, «Studio YABOT») → «Подключить почту». Программа сразу проверит вход.

Обычный пароль от почты не подойдёт — только пароль приложения. Отозвать доступ можно в любой момент там же, в «Паролях приложений»; тогда канал покажет ошибку входа.

## Как это работает

- Ящик проверяется раз в минуту. Письма **не помечаются прочитанными** — в Gmail всё выглядит как раньше.
- Агент отвечает только на письма, пришедшие **после подключения**. Старую почту не трогает.
- Рассылки, уведомления сервисов (`no-reply`, письма со ссылкой «отписаться»), автоответы и собственные письма ящика пропускаются.
- Одна переписка в «Диалогах» = один отправитель. Над перепиской видна тема письма.
- Процитированная часть старых писем отрезается — агент видит только новый текст. О вложениях агент знает только количество (сами файлы смотрит менеджер в Gmail).
- Ответ агента оформлен как письмо: приветствие, несколько абзацев, подпись «З повагою, команда …».
- Менеджер может «Взять диалог» и ответить сам — письмо тоже уйдёт из ящика.
- Переключатель «Ответы — на одобрение» в карточке канала: выключите, если агент должен отвечать сам без проверки.
