# Запись в Google Календарь

Агент сам находит свободное время в календаре клиента и создаёт в нём запись. Доступ к календарям идёт через **один сервисный аккаунт студии** — это «робот» Google со своим адресом. Клиенту не нужно входить через Google в нашей программе: он просто открывает свой календарь для адреса робота, как открыл бы коллеге.

## 1. Сервисный аккаунт (один раз на студию)

1. Откройте [console.cloud.google.com](https://console.cloud.google.com) под аккаунтом студии и создайте проект (например, `GenAgent`).
2. **APIs & Services → Library** → найдите **Google Calendar API** → **Enable**.
3. **IAM & Admin → Service Accounts → Create service account**. Имя любое (например, `genagent-calendar`). Роли проекта не нужны — пропустите шаги с ролями.
4. Откройте созданный аккаунт → вкладка **Keys → Add key → Create new key → JSON**. Скачается файл.
5. В GenAgent: **Интеграции → Google Календарь** → вставьте содержимое файла целиком → «Сохранить». Появится адрес сервисного аккаунта вида `genagent-calendar@проект.iam.gserviceaccount.com`.

Файл ключа после этого лучше удалить с компьютера: он хранится в базе программы. Если ключ утёк — удалите его в Google Cloud (Keys → корзина) и вставьте новый.

> Если в организации Google Cloud запрещено создавать ключи (политика `iam.disableServiceAccountKeyCreation`), её нужно отключить для проекта или создать проект в личном аккаунте.

## 2. Календарь клиента (для каждого клиента)

Клиент (или вы, если у вас есть доступ к его календарю):

1. [calendar.google.com](https://calendar.google.com) → слева у нужного календаря **⋮ → Настройки и общий доступ**.
2. **Открыть доступ пользователям → Добавить пользователей** → адрес сервисного аккаунта из «Интеграций» → право **«Вносить изменения в мероприятия»** («Make changes to events»). С правом «Просматривать только свободное/занятое время» агент увидит занятость, но записать не сможет.
3. Там же ниже, в **«Интеграция календаря»**, скопируйте **ID календаря**. У основного календаря это email владельца, у дополнительных — длинный адрес `...@group.calendar.google.com`.

Удобно завести для записи отдельный календарь (например, «Запись онлайн») — тогда записи агента не смешиваются с личными делами, а занятость всё равно учитывается только по этому календарю.

## 3. Настройка агента

Конструктор агента → **«Запись в календарь»**:

- включите «Записывать клиентов в Google Календарь»;
- вставьте **ID календаря** и нажмите **«Проверить доступ»**;
- укажите часовой пояс, рабочие дни и часы;
- добавьте **услуги** с длительностью (если длительность у всех одинаковая — достаточно «Длительность по умолчанию»);
- «Не раньше чем через, ч» — чтобы не записывали на «через 10 минут»; «Не дальше чем на, дней» — горизонт записи.

Сохраните агента. Навык «Запись на приём» при включённом календаре заменяется инструкцией с настоящей записью.

## Как это работает

- Агент вызывает `find_free_slots` — программа читает занятость календаря и предлагает время только внутри рабочих часов, с шагом 30 минут (или длительность услуги, если она короче).
- Когда клиент выбрал время и назвал имя и телефон, агент вызывает `book_appointment`. Перед созданием события занятость проверяется ещё раз — двойной записи не будет, даже если кто-то занял время секундой раньше.
- В событии: «Услуга — Имя», в описании телефон и комментарий.
- В «Диалогах» появляется отметка «Агент записал клиента в календарь».
- **Тест-чат и «Проверка» событий не создают**: занятость читается из настоящего календаря, а запись только имитируется. Под ответом в тест-чате видно, какие инструменты вызвал агент и что получил.
- Если календарь недоступен (доступ закрыли, ключ удалён), агент извиняется и передаёт диалог менеджеру — время он не выдумывает.

Отмена и перенос записей пока делаются вручную в календаре.
